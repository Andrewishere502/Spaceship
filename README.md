# Spaceship
This is pretty much just the classic game Asteroids, but my own version of it. This game is no longer being updated.

Explanation of settings:

combine_asteroids
    Makes asteroids combine when they collide.

flip_aim
    Flips the aim of the spaceship to
    be opposite of where the mouse is pointing.

speed_up_when_loop
    Makes the asteroids speed up when they loop
    around the screen as a punishment for not
    killing it. Suggested by my mom!

asteroids_do_damage
    Toggles the ability of asteroids to do damage
    to the spaceship.

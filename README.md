# Spaceship
Control a lone spaceship trying to survive against an onslaught of devious space rocks.
Inspired by [Asteroids](https://en.wikipedia.org/wiki/Asteroids_(video_game)).

## Available Settings
| Name | Description |
| ------- | ----------- |
| `is_combine_asteroids` | Makes asteroids combine when they collide. |
| `is_flip_aim` | Flips the aim of the spaceship to be opposite of where the mouse is pointing. |
| `is_speed_up_when_loop` | Makes the asteroids speed up when they loop around the screen as a punishment for not killing it. Suggested by my mom! |
| `is_asteroids_do_damage` |  Toggles the ability of asteroids to do damage to the spaceship. |
